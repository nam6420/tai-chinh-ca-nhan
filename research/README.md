# Nghiên cứu

Gợi ý cấu trúc:

```text
research/
  briefs/
  macro/
  sectors/
  companies/<market>/<ticker>/
  reports/
```

Ghi chú đang làm chưa qua kiểm chứng phải ghi `BẢN NHÁP - CHƯA KIỂM DUYỆT`. Không ghi đè dữ liệu gốc trong `data/raw/`.
