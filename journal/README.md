# Nhật ký

Lưu giả thuyết học tập, quyết định mô phỏng và bản nhìn lại sau sự kiện. Dùng `templates/decision-journal.md`.

Chi tiết quyết định thật, quy mô tài sản, mức lỗ chịu đựng hoặc thông tin tài chính cá nhân phải đặt trong `journal/private/` (được Git ignore) hoặc một hệ thống riêng phù hợp. Tuyệt đối không lưu đăng nhập, số tài khoản, API key hoặc dữ liệu cá nhân nhạy cảm trong repo.
